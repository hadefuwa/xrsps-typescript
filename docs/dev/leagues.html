1. Core Loop: Tasks & League Points (LP)

The heartbeat of Leagues. Players perform actions to complete Tasks, which award League Points. LP unlocks Relic tiers and Regions.

Task Definitions & Tracking ❌

Missing a system to define, trigger, and track thousands of tasks.

  • ❌ Event listeners for skilling, combat, quests, etc.
  • ❌ Task tiers (Easy, Medium, Hard, Elite, Master).
  • ❌ Task completion notifications & fireworks.
League Point (LP) Economy ❌

Missing the core point currency.

  • ❌ LP variable saved per player.
  • ❌ LP milestones triggering relic tier unlocks.
  • ❌ Task UI interface implementation (CS2/widgets).

2. Relic System & Passive Buffs

Game-breaking passive buffs unlocked through LP milestones.

Relic Selection UI ❌
  • ❌ Interface to choose 1 of 3 relics at specific tiers.
  • ❌ Server-side validation of relic choices.
  • ❌ Persistent storage of unlocked/selected relics.
Combat & Skilling Overrides ❌

Requires deep engine hooks.

  • ❌ Endless Harvest: Auto-banking resources + double yield.
  • ❌ Trickster: Auto-pickpocketing, stacked clues.
  • ❌ Ruinous Powers / Combat: Attack speed modifiers (e.g. 2-tick weapons).

3. Region Unlocks & Progression

Players start restricted and unlock new map areas via tasks.

Region Interfaces & Logic ⚠️
  • ✅ Widget for region selection (already prototyped).
  • ✅ Data storage for unlocked regions.
  • ❌ Logic to spend Region Unlocks (earned via LP).
Map Enforcement ⚠️
  • ✅ Design plan exists (leagues-region-enforcement-plan.html).
  • ❌ Pathfinding truncation not yet coded.
  • ❌ Fallback teleport (Edgeville) not yet coded.

4. XP & Drop Multipliers

Leagues features massive progression boosts that scale as the player advances.

Dynamic XP Multipliers ❌
  • ❌ Base XP multiplier (e.g., 5x).
  • ❌ Tiered XP multipliers (scales up to 12x or 16x based on Relic Tier).
  • ❌ Minigame point multipliers (e.g., 5x Pest Control points).
Boosted Drop Rates ❌
  • ❌ Global drop rate multiplier (e.g., 2x to 5x for rare tables).
  • ❌ Clue scroll drop rate enhancements.
  • ❌ Clue step reductions (Leagues clues are usually only 2-3 steps).

5. Economy & Ironman Constraints

Leagues players exist in a vacuum separated from the main economy.

Ironman Enforcements ❌
  • ❌ Disable trading for League profiles.
  • ❌ Disable Grand Exchange access.
  • ❌ Restrict item pickup from other players/PvP.
Shop Alterations ❌
  • ❌ Leagues-specific shop stocks (higher restock rates).
  • ❌ Flat shop pricing (prices don't change based on stock).
  • ❌ Separate instance of shop inventories for League vs Main game.

6. League-Specific Mechanics & Items

Iconic Features ❌
  • ❌ Last Recall: An item that stores coordinates of the last teleport and allows returning instantly.
  • ❌ Unlimited Run Energy: Globally applied to all League players.
  • ❌ The Sage / Tutor: NPC to claim League rewards, tools, and interface access.
